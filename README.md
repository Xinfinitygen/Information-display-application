# Favorite Books App

A simple React application that displays a list of books. Built as a coding assignment.

## Features
- Built with React functional components (`Header`, `BookList`, `Book`)
- Uses props to pass book data
- Styled with external CSS

## How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npm run dev
   ```
   *(Or `npm start` if using Create React App)*
