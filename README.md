# React Component Assessment

A React project containing two component-based assessments focused on building reusable components, passing data through props, and styling React components with CSS.

## Assessments

### 1. Favorite Books

A simple information display application built with reusable React components.

The application includes:

- A `Header` component displaying the page title.
- A `BookList` component for displaying a list of books.
- A reusable `Book` component that accepts a `title` prop.
- Three favorite book titles.
- CSS styling for the application.

### 2. Reusable Contact Card

A reusable contact card component created from a provided HTML `<li>` structure.

The `ListCard` component accepts contact information through props:

- `name` — Contact's name
- `job` — Contact's job title
- `email` — Contact's email address

Multiple contact cards can be created using the same reusable component with different prop values.
